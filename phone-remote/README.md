# 小马蓝牙遥控 0.4.0

0.4.0增加独立“儿歌”页，底部为遥控 / 听书 / 儿歌 / 电台 / 应用。读取SD卡的20首中文儿歌，每页3首；显示当前歌名、播放进度、播放/暂停/继续、上一首/下一首、停止、音量、顺序/随机/单曲循环，以及关闭/15/30/45分钟睡眠定时。最后两分钟声音渐弱、屏幕渐暗，到时离线晚安并停止。打开页面、读取曲库不会自动播放。

需要开发板 **s3.48+** 和儿歌 **0.1.1+**，当前设备已配套更新。手机与设备共用独立儿歌播放模式，原听书模式、30篇故事和书签保持独立；歌曲仍在开发板SD卡播放，手机不下载或传输音频。歌曲控制沿用锁屏、家长听书授权、休息时间和音量上限；不能用儿歌的暂停/停止/定时误控制正在播放的故事。旧固件提示更新，原有功能继续保留。

安装 [xiaoma-remote-0.4.0.apk](../packages/android/xiaoma-remote-0.4.0.apk)，原证书签名，直接覆盖0.3.0后重新连接设备即可。

s3.49修复蓝牙遥控在多次使用后因连续内部内存不足而无法开启的问题；调整内部DMA预留池并保留启动检查，增加启动前内存诊断。安卓0.4.0安装包继续使用，详见[蓝牙内存与复测](BLE_MEMORY.md)。

0.3.0新增独立“电台”页，底部导航为遥控 / 听书 / 电台 / 应用。频道列表与设备同源，按儿童、音乐、资讯分类；显示频道名、语言/简介、Wi-Fi与播放状态，支持上一台/下一台、播放/暂停/继续、停止、音量和关闭/15/30/45分钟定时。打开页面或加载列表不会自动播放。音频由设备通过Wi-Fi播放，手机仅通过加密BLE遥控。

电台控制需要 **s3.45或更新固件**；旧固件会提示升级，其余原有遥控、听书、应用功能继续可用。锁屏及儿童模式仍由设备拒绝未授权操作；频道只能选择内置八台，不接受任意网络地址。更换频道会清除当前电台定时，需要时重新设置。已有收藏仍在设备电台页管理。


0.2.3将手机听书页的“停止”替换为“下一篇”，暂停和继续保留。点击时串行读取完整分页书架和当前播放状态，再使用已有`play`指令从头播放下一篇，无需更新s3.40固件。顺序和单篇循环模式手动前进一篇，末篇回首篇；随机模式选择其他篇目，单篇书库重新播放该篇。倍速保持当前档位。空书库、已移除的当前故事或同名导致无法唯一定位时提示从书架选择，不误播。

0.2.2在听书页增加六档倍速选择：0.5 / 0.75 / 1 / 1.25 / 1.5 / 2，开机默认1倍，配合固件s3.40、听书0.3.6。倍速与设备同步，原签名覆盖安装。见[倍速说明](../codex-quota-monitor/AUDIOBOOK_SPEED.md)。

安卓手机直接通过BLE控制ESP32-S3设备，不需要同一Wi-Fi，也不需要电脑中转。手机需要在设备的蓝牙覆盖范围内。本轮优先实现蓝牙，跨网络遥控暂缓。

## 安装与连接

当前设备端使用固件 **0.8.3-s3.49**、儿歌0.1.1、听书0.3.6和s3.34独立蓝牙设置资源；安卓端安装 [xiaoma-remote-0.4.0.apk](../packages/android/xiaoma-remote-0.4.0.apk)，支持Android 8及以上。

1. 设备进入 **设置 → 蓝牙 → 开启蓝牙遥控**。先停止正在进行的播放或录音，再开启入口；开启后可从手机播放故事。
2. 屏幕会显示 `CTRL_XXXXXX` 和4位数字临时配对码（例如 `0042`，需输入开头的0）。原来的“开始配网”仍用于乐鑫ESP BLE Prov，设备名为 `PROV_XXXXXX`。
3. 手机打开“小马遥控”，允许“附近设备”权限，点击“扫描设备”；旧版Android还需要允许定位并打开系统定位开关。
4. 输入设备显示的配对码，点击扫描出的设备。连接成功后可调整音量和亮度，分页查看应用、故事并点击打开或播放。

从手机选择故事或进行听书控制时，设备先切到听书页面，再执行播放、暂停、继续或停止。支持息屏、唤醒和锁屏。亮度可调10%至100%，音量0至100%仍经过设备原有音量上限和勿扰逻辑。锁屏后仅能读取状态，需在设备上快速连按两次音量＋解锁。儿童模式下不能从手机直接打开应用，听书仍受原家长授权限制。

每次开启生成新配对码，窗口最多30分钟，成功连接不会延长窗口；再次点击设备上的“结束连接”即可关闭。配网与遥控共用蓝牙硬件，每次只开启一种模式。当前为前台遥控应用，没有后台常驻服务，也不保存配对码。此应用无需互联网、麦克风或云端账号。

s3.38的四位配对码使用安卓0.2.0，使用原签名可直接覆盖安装，无需卸载。乐鑫ESP BLE Prov的Wi-Fi配网流程和原8位配对码保持不变。

s3.36针对连续打开多个应用后的失败，切换时先关闭上一应用页面，退出脚本应用时释放运行环境；原生设置等应用保留界面缓存，加快再次进入。在线助手的断开请求是异步的；开始下一应用前等待音频所有权释放，确保网络回调停止、大录音缓冲已回收，最多等待20秒，超时则提示稍后重试。后台服务按各应用原有关闭逻辑处理；听书页面关闭仍会停止听书。遥控指令由独立协调循环执行，避免打开应用时的嵌套服务调用占满共享线程。屏幕SPI最大传输块设为4092字节、队列深度设为1，避免两笔较大的内部DMA临时缓冲与蓝牙争抢内存。保留整屏PSRAM绘制及现有壁纸。同步系统任务即使抛出异常也会完成等待结果，返回原始错误，避免调度器捕获异常后调用方永久等待。需同时安装电子宠物0.1.3，按当前动作缓存两到三张帧，避免一次预载八张帧的内存峰值。应用商店的存储、网络及界面异步回调转由应用定时任务统一处理，关闭时丢弃旧回调并取消迟到的HTTP请求，避免后台回调访问已经释放的页面上下文。USB状态另提供当前生命周期阶段，便于区分卡在加载、关闭或挂载。安卓端仍用0.1.0，独立蓝牙菜单资源沿用s3.34。

已有s3.34/35设备升级时只更新应用分区，并运行 `python codex-quota-monitor/tools/deploy_virtual_pet.py --port COM3` 安装宠物0.1.3；已有SD动画帧与自定义作息继续使用。

## 协议与验证

儿歌新增`songs`（每页3首）、`song_status`、`song_play`（仅曲库整数编号）、`song_previous`、`song_next`、`song_pause`、`song_resume`、`song_stop`、`song_mode`和`song_timer`。`status.songs_supported`用于判断能力，儿歌状态单独读取，每条BLE回复限制480字节。
