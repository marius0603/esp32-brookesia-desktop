# 高德导航通知转发 0.5.4

0.5.4清理进入路名后的分隔附加内容：保留“进入某路”，截掉｜、|、中点及换行后的元数据，过滤私有图标/不可见/替代字符，不改变转向与距离识别。手机与蓝牙发送文字共用清理规则，原始通知仍仅在本机调试详情暂存。匹配设备导航0.2.1也有同样清理，旧手机包仍可由设备先清理。

2026-11-11用户已确认0.5.3在后台1～2分钟持续同步、未再过期；这是现场短时验证，不代表跨厂商或长期锁屏运行均已验证。

0.5.3修正后台仍连接却停止同步：0.5.2将“15秒没有通知发布事件”等同于通知无效；用户实测蓝牙和前台服务仍在，设备收到的指引却过期。现每2秒从系统核对当前仍存在的高德导航通知，区分“当前通知已核对”和“指引文字有变化”。只要系统确认有效通知仍存在，就维持该原始指引的蓝牙同步，不推算移动、距离或新路况；文字变化年龄独立保留在调试详情。

优先选择有转向/距离的导航通知，普通后台提示不覆盖更完整的活动指引；补读公开的title.big、summaryText、infoText和ticker文字。通知移除/结束、通知监听断开或系统核对持续失败时停止转发，设备仍按15秒无数据包过期。停止请求遇蓝牙忙时保留至当前请求结束，避免丢掉停止事件。所有文字仍仅RAM处理，不调用高德API、不写入日志。

安装原签名0.5.3（versionCode14），无需修改设备端。解析/通知选择/内容不变时的活动租约/核对失败超时/移除与结束/开关边界测试及签名构建通过；用户已确认短时后台持续同步、不再过期；长期锁屏仍未验证。调试详情显示蓝牙、通知监听、前台服务、系统核对次数、最近核对与文字变化年龄，便于区分链路中断和高德内容未变。

0.5.2将通知页统一为遥控主页的深蓝卡片/薄荷绿风格：连接状态与默认同步开关、图形转向/大号距离、语音与后台、授权入口；原始通知折叠到调试详情。新增connectedDevice前台服务及常驻通知，复用原BLE连接，在手机切到高德或主页时保留进程前台优先级；通知提供停止同步入口。MainActivity返回键在后台服务运行时退到后台，方向/屏幕/主题配置变更保留当前连接。

安装原签名0.5.2（versionCode13），连接蓝牙后自动尝试开启后台服务，也可在通知页点“开启后台运行”授予通知显示权限。当前仍复用原MainActivity会话，并未增加服务独立GATT控制器；结束/强杀遥控、系统回收会话或断开蓝牙后仍需重新连接。后台服务不保证所有厂商省电策略下永久运行。编译/原签名及权限声明校验通过，手机切后台/锁屏持续转发仍需现场验证。

官方机制：[connectedDevice前台服务](https://developer.android.com/develop/background-work/services/fgs/service-types#connected-device)。

0.5.1按用户要求默认开启通知同步；手动关闭/开启的选择会存入本机偏好，通知服务重连后恢复选择。首次仍需用户手动授予通知使用权，并完成蓝牙配对；只有新鲜导航通知才会转发，不改变15秒过期规则。安装原签名`packages/android/xiaoma-remote-0.5.1.apk`（versionCode12）覆盖旧版。

用户选择的当前方案：手机高德App负责真实导航，小马遥控经Android通知使用权读取它的导航通知，通过原加密BLE连接转发给ESP32。无需开发者Key，不带高德SDK，不发高德API请求；公开Manifest无INTERNET权限。高德App本身的使用与联网由它的服务规则决定。

安装`packages/android/xiaoma-remote-0.5.0.apk`，原证书/包名，versionCode11，可覆盖0.4.0和旧私有试验版。原遥控、听书、儿歌、电台和应用页继续保留。

## 首次实测

1. 打开“导航通知转发”，点“前往系统开启通知使用权”，阅读说明并在系统页面手动授权“小马遥控”。Android此权限范围较广，本代码首先按包名`com.autonavi.minimap`过滤，其他App通知不读取正文、不保存、不转发。
2. 在手机高德App启动导航，再返回此页。它显示实际的title/text/bigText/subText/textLines及保守识别结果，先核对有没有转向、距离和道路信息。无需提供具体位置或道路名称。
3. 在遥控首页与设备配对连接，打开通知页勾选“将高德导航通知同步到设备”。设备需s3.64及导航0.1.0并退出儿童模式；新会话自动打开设备导航页。
4. 关闭转发、结束高德导航或移除其通知会尝试发送停止。若蓝牙忙或中断，设备最迟在15秒收不到更新后显示过期、停止提示。设备端可关闭语音，系统勿扰与音量仍有效。

标题/正文等通知文字仅RAM暂存，不写日志、不上传服务器；无网络接收端，不调用手机定位接口。通知包含哪些字段、更新频率和后台保活必须在用户手机实测，不能由Android接口存在推断高德一定提供完整导航数据。

## 设备语音策略（导航0.2.2 / s3.66）

远处指引不自动播报；进入100米、30米范围各提醒一次，通知正文变化不重复提醒。先收到30米内的转向、后切换到150米以外的下一段指引时，播一次“请继续按导航行驶。”；这只是通知状态切换，不代表设备具有独立定位或能判断实际越过路口。到达一次，未知方向自动静音；手动重播保留。系统静音、勿扰、数据过期或停止时不播。

## 已知边界

- 仅支持安卓高德包名，不支持iOS或其他导航App；无通知文字或方向时保留未知，不进行OCR/无障碍读取或猜测箭头。
- 不调用SDK补齐缺失字段，不反查地址，不自动充值/购买服务。通知转发不增加高德开发者API请求。
- 设备仍依赖手机蓝牙。0.5.2增加前台服务保活当前会话，退出/杀死遥控或系统回收会话后需重新连接；未增加自动重连或独立GATT控制器。
- 0.5.3以系统核对“当前通知仍有效”维持转发，文字不变不会伪造新的距离或内容更新时间。若系统核对失败，不刷新核对时间，最长10秒后停止发送；设备随后按15秒无包过期。通知被移除/结束则尝试直接发送停止。
- 固定离线语音不朗读任意路名；只播明确识别的转向，跳过未知方向，不抢占其他音频。

## 验证

Java合成通知解析覆盖方向/未知/下一步与剩余距离区分/时间/停止；设备UI覆盖未知字段、过期、停止、深浅色、暂停及语音重复/阶段/勿扰/静音。

2026-11-11用户确认手机能读取转向和距离。首次反馈未同步时，设备刚开启蓝牙遥控、尚无新导航帧；完成连接后用户确认“可以了”。设备随后读回来源2（高德通知）、序号46、数据年龄6ms，方向/距离均已识别，导航App运行且无错误；本地提示已写入67200字节PCM且无播放错误。真实通知到设备的基本链路已验证。记录不含通知正文、路名或位置；长时间后台/锁屏运行、不同手机和高德版本仍未完成验证，提示音听感未单独复核。
