# 安卓儿歌页验证（2026-11-04）

版本：安卓0.4.0（versionCode 8）、固件s3.48、设备儿歌0.1.1。旧版安卓0.3.0保留；新版使用原证书签名，可覆盖安装。手机实际布局和安装操作仍需用户现场确认。

- APK全部Java源码编译、DEX、资源链接、v2/v3签名验证通过，签名证书与加密备份清单一致。没有新增互联网、麦克风或存储权限。
- 原APK的Java Security1代码与独立Python实现核对官方protobuf、X25519/PoP证明及连续AES-CTR双向字节流通过。真实蓝牙联调用同一份Java协议代码加密，不使用未认证的控制入口。
- 实机七页读取全部20首儿歌，逐项与设备曲库一致；第八页为空，不自动播放。原30篇故事、14个应用和八台电台目录保留。
- 真实BLE验证选曲并切到设备儿歌页、PCM输出、暂停/继续、上一首/下一首及首尾环绕；三种儿歌模式共享且保持当前曲目和原听书模式；15/30/45分钟及取消定时均通过。
- 手机调音请求20/45/0后，读回实际codec音量、DAC寄存器和儿歌状态一致；蓝牙状态轮询期间连续输出20秒，PCM断粮0次，最大输出间隔13.311ms，PCM任务最小剩余栈2488字节。这不是任意运行时间或任意SD卡的流畅度保证。
- 所有实测BLE回复最大261字节，低于480字节上限。无效曲目编号、URL、负数/小数页码、模式、定时和任意服务调用被拒绝。
- 儿歌的停止、暂停、继续和定时请求在故事播放中被拒绝，不会停止或改写故事。读取状态不把儿歌冒充正在播放的故事。
- Java逻辑检查覆盖播放/暂停/继续、状态文字、睡眠定时向上取整与七页范围；原听书下一篇及电台分类导航检查通过。设备端儿歌JS回归新增远端模式刷新检查，听书/电台原有JS回归通过。
- 联调结束关闭临时蓝牙窗口，恢复音量、深睡选项、原生儿歌模式、故事和儿歌的书签/模式文件；电脑蓝牙恢复测试前状态。配对码只在内存及测试Java子进程环境中使用，不记录到日志或仓库。

私有报告：`codex-quota-monitor/runtime/songs-phone-verification.json`。完整Flash备份、运行日志、配对信息、明文JKS、工具链和下载音频均不上传。

复现：

```powershell
python phone-remote/tests/verify_android_protocol.py --tools <tools.json> --idf <esp-idf> --work <private-protocol-classes>
python phone-remote/tests/verify_songs_device.py --port COM5 --tools <tools.json> --classes <private-protocol-classes>
```

测试要求设备处于未锁屏的家长模式、播放和定时均已结束，电脑蓝牙已开启；不绕过PIN、家长授权或休息限制。手机界面只发送限定命令和曲目编号，音频始终由设备从SD卡读取。
