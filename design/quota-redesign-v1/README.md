# 额度 App 设计预览

本目录保留最初的设计预览，不直接用于设备资源。用户认可后，方案已集成额度App0.2.5；实机数字字号和高度按显示效果调整，百分号采用原生实测宽度定位。

两个配色使用相同的480×480排版，拟跟随系统深浅模式。去掉渐变和粗轨道边框，使用统一色面的双卡片；左侧突出百分比，右侧以时钟图形区分重置倒计时，每周的天数独立成行。底部保留吃豆人和代表真实剩余额度的豆子。顶部只保留同步状态，不增加页面标题。

预览中73%/64%及倒计时均为演示数据，图片不是设备截图。PNG用于查看布局，GIF演示嘴部开合；动画速度、字体与间距需在实际开发时上板核对。设计不改变60秒请求、15秒超时、Codex联动等同步规则。

`render.py`用Pillow从绘图指令生成预览，使用Windows黑体与Segoe UI字体，不包含账号信息。产物为`preview.png`和`preview.gif`。
