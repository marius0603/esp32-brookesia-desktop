# 猫咪时分秒翻页表盘：排版及动画预览

2026-11-09，按用户最新参考照片调整。此目录替代v3作为当前设计草案，
尚未改变生产App、版本号或开发板。

- 第一行：小马时钟、Wi-Fi、电量；第二行：日期在左、天气温度在右。
- 第三行：六个数字组成HH:MM:SS，同一字号82px；其他状态字22px。
- 数字有克制的深色分体面板和中缝，只对变化数字进行360ms上下翻页。
- 猫咪场景横向铺满，沿用已授权的日景/夜景插画及敲键盘姿态；圆点置底。
- 不添加参考照片中未要求的CPU/RAM信息或底部功能按钮。

PNG与GIF为480×480设计渲染，日期、天气、网络和电量均为示意值。
GIF从12:29:58演示至12:30:03，包含秒翻页及整分钟多位同时翻页。
六秒循环回到起始时间；此循环重置只是演示，不代表真实时钟倒退。

`render.py` 使用Pillow及Windows微软雅黑/Bahnschrift渲染原生界面元素，
从现有昼夜图集裁切并缩放猫咪插画，无需再次生成素材。
时间翻页与猫咪动画并行仅在电脑预览，尚未验证设备帧率、显存或功耗。
