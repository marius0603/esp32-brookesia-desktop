# 图形导航界面预览

本目录保存设计预览。用户随后授权实装，图形布局已并入设备导航0.2.0；生产资源位于brookesia-apps/navigation，系统固件仍s3.64。本图不是实屏截图。

- 480×480画布，深色/浅色跟随系统。
- 顶部：蓝牙状态、扬声器图标+实际系统音量百分比、电池图标。
- 中部：单个大转向箭头、大号距离，短路名/指令作为辅助。
- 下部：终点图标+剩余距离、时钟图标+剩余时间；语音播报开关及音量减/加。
- 保留现有本地中文语音。未来实装应读取系统音量，保留勿扰与实体键联动；未知字段显示--，过期隐藏方向并停止播报。
- 图中200米、70%、2.4km、8分钟和示例路均为占位数据，不代表真实路线。

`build_preview.py`使用Pillow绘制原生图形和文字，可重建两款480×480单图及对照图。字体使用Windows微软雅黑。
