# 图像生成说明

通过Codex内置imagegen生成，非CLI/API回退。两幅图以用户选中的丰富版赛博朋克双页桌面概念图为风格参考。

壁纸提示：生成单独的正方形设备壁纸，保持参考夜城的深海军蓝天空、青紫霓虹建筑、低处青粉渐变太阳、河水、桥与前景；上部约55%为暗色平静天空，下部45%集中城市。保持少量光晕和清晰建筑轮廓，适合480×480 AMOLED；完全去除图标、文字、状态栏、边框和分页点。

图集提示：生成一张严格5列2行的10图标图集，所有格子等尺寸、深色纯背景、正面视图，深色玻璃金属圆角方底、青紫发光边缘、丰富2.5D微缩场景。按顺序绘制：齿轮与控制滑块及扳手；文件箱与文档、照片、波形卡；应用售卖机与下载指示；双周期额度时间仪表；云、太阳、雨、闪电和温度计；故事书、耳机、月亮、城堡；机械翻页时钟；戴麦克风耳机的机械马、对话框及声波；防护罩里的玩具机器人、积木及锁；含猫狗动物卡、ABC、1+2及麦克风的学习书。使用一个明确主体和少量相关辅助物，保持92像素时可辨认；不添加图标名称、标题、桌面截图或多余图标。

生成原图保持原样。安装导出仅做已记录的裁切、统一尺寸、深色补边和RGB565/RLE转换，不再生成或替换图中物体。
