# 单次录音诊断与文件转写

默认设备录音只在电脑内存中识别。排查录音不完整、削顶或噪声时，可显式要求仅保留下一次提交的录音：

```powershell
python pc-voice-bridge/arm_diagnostic.py --target G:/codex_data/qwen-speech
```

让使用者知道会在本机留存这一段录音，再由使用者在设备点击说话、说完发送。原始16kHz、16位单声道PCM以WAV保存于运行目录 `outputs/diagnostics`，旁边JSON记录时长、峰值、RMS、直流偏移、削顶及零值比例。采集一次后自动关闭。取消尚未发生的采集：

```powershell
python pc-voice-bridge/arm_diagnostic.py --target G:/codex_data/qwen-speech --cancel
```

诊断不会额外把录音发送到文本模型接口；正常助手仍仅向配置的云服务发送识别文字。诊断文件、运行配置及日志不得提交Git。写入诊断失败时保留错误提示，继续正常的识别流程。

文件转写页面已修复TTS分支的局部 `base64` 导入遮蔽全局名称的问题；此前ASR分支会在解码上传文件前报局部变量未赋值。上传文件解码及调用常驻识别进程的回归测试通过，真实短WAV也已通过本机转写接口处理。过短或缺失音节的样本不能用于判断模型是否能正确识别完整句子。

验证：单次采集保留PCM原字节及质量指标、未开启时不留存、采集后自动关闭、文件转写入口，以及已有对话/传输测试共12项通过。部署工具跳过工作台目录中的缓存子目录，保留私有配置和模型。
