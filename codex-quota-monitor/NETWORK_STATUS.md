# 联网故障恢复

固件 s3.74 配套电台 0.1.5、天气 0.2.11、小马助手 0.2.4 和额度显示 0.2.6。四个页面沿用底边上滑返回桌面。状态提示留在原页面，电台等待时可按“停止”，助手连接时可按“取消连接”。

| 提示 | 显示时机 |
| --- | --- |
| 未联网 | 设备 Wi-Fi 断开 |
| 连接中 | Wi-Fi 正在连接，或应用正在尝试连接服务、获取内容 |
| 服务不可用 | Wi-Fi 已连接但服务报错或请求超时。额度页通过 USB 请求电脑采集，收不到电脑响应也显示此提示 |
| 数据过期 | 缓存天气满 30 分钟，或额度超过数据包给出的有效期。保留上次读数 |

- 电台检测到 Wi-Fi 断开后等待约 30 秒。期间重新联网会继续当前频道。等待用完后停止，联网后可手动再播。服务不返回可用内容时最多自动再试三次。正常收到新的流数据后可恢复播放。
- 天气失败后分别在 10 秒和 30 秒后再试，总共最多三次尝试。Wi-Fi 恢复或点击“刷新”会重新开始。平时仍每 10 分钟刷新。
- 助手的电脑模式限制连续 WebSocket 传输失败次数，小智连接信息请求最多连续尝试三次。可从页面手动重试，退出会释放连接。
- 额度显示平时每 60 秒请求一次。单次等 15 秒，失败最多再试两次，需要重新登录时可登录后点“刷新”。退出会撤销页面的采集请求。

已有设备先刷 s3.74 应用分区，再运行 `python codex-quota-monitor/tools/deploy_network_status.py --port COM5` 更新四个 SD 应用并重启。部署会逐文件核验、保留原应用树备份。

电台的断网恢复与连续播放是两项验证。苏州台和 Fun Kids Naps 的历史停顿保持待排查。

实机核对了天气断网保留缓存及联网后更新、助手离线时不发起连接及联网后重新尝试、额度缓存显示数据过期以及恢复电脑采集后显示“已同步”。电台实机通过长时间断网停止和断网时退出；频道恢复结果见[电台实机验证](../brookesia-apps/radio/VERIFICATION.md)。
