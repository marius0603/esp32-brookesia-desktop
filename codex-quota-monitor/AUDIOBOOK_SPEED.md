# 听书倍速（s3.40 / 听书0.3.6 / 安卓0.2.2）

提供0.5、0.75、1、1.25、1.5、2倍速。系统启动默认1倍速，不写入Flash偏好；同一次开机中暂停、换故事或重开听书保留当前倍速。睡眠定时按真实时间计算，书签和进度仍表示原故事的位置。

设备听书页底部新增倍速按钮，点击循环切换；手机听书页“播放方式”卡片内提供六档选择列表。两端通过原生`Audiobook.SetSpeed {Speed: 倍数}`共享，`GetState.speed`及BLE状态`story_speed`返回当前值。非法档位被拒绝；锁屏与儿童模式原有限制继续生效。

处理链：解码 → 16kHz单声道 → [Sonic时间伸缩](https://github.com/waywardgeek/sonic) → 双声道复制 → 64KiB PCM队列 → 喇叭。通过时间伸缩尽量保持音高，晚安及剩余时间提示保持原速。Sonic源码固定提交、Apache-2.0许可及PSRAM分配适配说明随固件保存。切换后已有队列中的短暂音频会先播放，随后使用新档位。

更新已有s3.39设备前先做本地完整备份，然后使用应用分区更新器安装`packages/firmware/brookesia-0.8.3-s3.40-app-only.zip`，再执行：

```powershell
python codex-quota-monitor/tools/deploy_audiobook_speed.py --port COM5
```

最后重启开发板刷新页面资源缓存。安装器逐项备份、更新并读回核对脚本、版本清单、页面及资源入口，保留SD故事、书签、原主题图标及其他资源。手机安装`packages/android/xiaoma-remote-0.2.2.apk`，沿用原证书覆盖安装。

验证工具`tools/verify_audiobook_speed.py --port COM5`生成临时4秒WAV，检查默认1倍速、六档输出PCM字节数及实际耗时、暂停后换速/跳转和非法档位拒绝，结束后移除临时文件并恢复音量和偏好。运行前关闭其他USB客户端，取消睡眠定时并解锁。

2026-11-02实机验证通过：六档耗时依次为8.265 / 5.562 / 4.188 / 3.469 / 2.891 / 2.406秒，包含启动与排空延迟；PCM输出字节数依次为512344 / 340516 / 256000 / 204312 / 170216 / 127612，均符合4秒原音频按倍速转换的输出量，队列断粮均为0，输出任务栈最少空余6976字节。暂停后变速、跳转、非法档位拒绝通过。用户已在开发板确认六档切换正常、播放流畅；安卓0.2.2的六档选择与状态同步已随安装包提供，手机端操作待安装确认。

另以44.1kHz《小公鸡和小鸭子》在2倍速连续播放12秒，源故事进度达到22秒，队列断粮为0。测试后已清除临时WAV，恢复1倍速、原故事偏好和音量。验证未覆盖整本长时连续播放或声学音高测量。
