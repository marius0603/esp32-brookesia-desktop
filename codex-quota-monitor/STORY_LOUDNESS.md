## 复用处理工具

使用`tools/normalize_story_audio.py`处理私有音频副本：

```powershell
python codex-quota-monitor/tools/normalize_story_audio.py --ffmpeg <ffmpeg.exe路径> --input <原始MP3> --output <私有新副本.mp3> --lufs -14
```

工具检测严重声道抵消，以限幅后重新编码的实际文件为准迭代匹配响度，允许误差0.35 LU、真峰值上限-0.8 dBTP，并检查完整解码时长；不覆盖原文件。输出旁保存逐篇测量、输入输出SHA256和所选声道的JSON。输出需位于Git仓库外或忽略的`codex-quota-monitor/runtime`目录。
