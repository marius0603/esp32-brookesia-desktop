# 统一儿童模式

当前固件 0.8.3-s3.27 与应用 `local.childmode` 0.1.1 配套使用；最初版本为 s3.11 / 0.1.0。
桌面打开“儿童模式”，由家长在设备上设置并重复确认六位 PIN，再开启模式。
没有默认 PIN；不用把 PIN 发到聊天中。

默认保留听书、天气、时钟和“儿童模式”家长入口。
额度、文件、应用商店、普通设置及未来新安装的应用均不在默认白名单。
家长可单独开关听书、天气、时钟、小马助手及轻学习；关闭儿童模式后恢复完整桌面。
升级不会自动授权轻学习，家长需在“可用应用”中开启。轻学习在设备本地播放名称和英语示范，跟读仅录音回放，不打分；录音在内存中，切换内容或退出即清除。
白名单在系统启动 App 的入口执行，隐藏图标之外也会拒绝未授权的启动请求。

默认音量上限 30%，可在 10%～60% 调整。这是设备音量百分比，不是声压测量值。
音频服务和硬件编解码器共同限制输出；听书、语音助手读取实际受限后的音量显示。
默认每日使用 30 分钟，可选不限制、10/20/30/45/60/90/120 分钟。
儿童应用位于前台或音频服务工作时计时，达到上限会停止儿童应用与音频，并阻止再次启动。
计时按分钟向上预留并持久化，重启不会重新获得已经预留的分钟。
北京时间跨日后重置；尚未同步网络时间时延续已用额度，不靠重启清零。
家长可用 PIN 重置今日时长。

夜间休息默认关闭；开启后默认 21:00～08:00，可调整整点开始/结束时间。
夜间限制开启但时间尚未同步时，暂停儿童应用，家长入口仍可使用。

语音助手默认关闭。家长开启时需再次点击确认“语音会上传小智”。
现有助手在点击说话后才采集并上传，保留原有栈保护；撤销权限或进入休息限制后会断开。
该开关授予语音功能，不代表模型回答已通过儿童内容过滤；平台角色与内容策略需另行配置和验证。

家长验证错误五次后暂停验证一分钟；重新启动也会重新执行该等待。
PIN 仅以随机盐和 PBKDF2-HMAC-SHA256（10000 次）结果保存在 NVS `ChildModeV1`。
会话令牌由设备随机生成，有效期 60 秒；页面闲置 45 秒、离开或关闭时自动锁定。
PIN 的 PBKDF2 运算通过 JS 原生桥调用时显式等待 15 秒，避免默认 1000ms 超时导致
后台已验证、前台仍留在输入页。校验时显示等待提示；错误会保留到下一次操作。
页面闲置使用定时器计数，不受联网校时跳变影响；四个面板的显隐一次批量更新。
忘记 PIN 需要连接电脑维护，设备界面不提供免验证清除。
这是设备界面的家长控制；开发电脑的固件维护、USB 文件操作及物理 Flash 访问仍属于受信任维护通道。

开发实现位于 `platform/super_s3_216/main/modules/child_mode`。
设置初始化、NVS 读取及计时保存由内部 RAM 栈任务执行，避免从 PSRAM 任务栈访问 Flash。
启动时使用 Python hashlib 的固定参考向量检查 PIN 派生算法。
原生服务 `ChildMode` 提供 GetState、SetupPin、VerifyPin、Configure、Lock、ResetUsage、ChangePin、ClearPin；
除公共状态及首次设置外，修改操作都要求有效的家长会话。ClearPin 还要求先关闭模式。

`tools/verify_child_mode.py --reboot-check` 仅用于家长尚未设置 PIN 的首次安装测试。
使用临时随机测试 PIN；私有 `runtime/child-mode-test-only.json` 用于中断恢复，成功后删除。
测试被中断时，用 `--cleanup` 验证该临时 PIN 并清理；不要把此文件提交到 GitHub。
已设置正式 PIN 时，测试脚本会拒绝运行。

儿童模式使用独立的“大马和小马”亲子图标，与奶油色手绘桌面统一。
原图、96×96 导出和生成提示保存在 `brookesia-apps/child-mode/artwork`；
重新生成 UI 时从该目录复制，不再复用设置的齿轮图标。

`tools/verify_child_lifecycle.py` 从桌面开始，对儿童模式、时钟、听书进行短时打开和关闭检查，
仅关闭这三个指定应用，并记录每轮内存快照；不会关闭系统桌面。
短时检查不替代长时间运行测试，也不能证明不存在内存泄漏。
