## 操作

打开应用自动扫描 SD 卡 `/sdcard/audiobooks/` 中的 MP3/WAV（含两层子目录，最多 512 章）。上一章、播放/暂停、下一章使用大号触摸按钮。0.3.0 移除前进/后退 30 秒按钮及动作订阅，睡眠定时合并为一个“关闭 / 15分钟 / 30分钟 / 45分钟”选择框；选择后立即生效，轮询只同步选中项，不重新开始计时。重新打开/恢复应用会刷新书单。

听书 Q 版图标直接放在应用包内，与现有主题的紧凑图标一致，重新安装应用也保留 Q 版外观。

## 锁屏

点“锁屏”后立即拦截全部触摸并关闭 AMOLED 显示，故事与睡眠倒计时继续运行。触摸、单按或长按不能解锁；**音量＋连续短按两次**，每次按下不超过 350ms、两次释放间隔不超过 650ms，解锁并点亮屏幕。长按产生的重复事件不计入双击。锁屏期间两个音量键不调节音量，解锁手势也不改变音量；解锁后恢复原来的单按与长按调音量行为。中间电源键仍由 PMU 控制。

锁屏在原有按键轮询和触摸过滤中完成，无额外常驻任务。锁屏期间暂缓自动深睡，以免触摸唤醒绕过本次锁屏；重启或关机结束本次锁屏。按键尚未初始化或设备正在进入深睡时拒绝锁屏。

旧s3.23首次增加锁屏的历史步骤：先运行 `tools/backup_current_firmware.py --port COM3` 生成并验证完整 Flash 备份，再使用 `tools/update_brookesia_app_only.py --port COM3 --build <build目录或解压后的应用分区包目录> --backup <本机备份目录>` 更新 s3.23 应用分区；工具核对 MAC、分区表、备份哈希与写入后校验，保留 NVS、LittleFS 和 SD。然后运行 `tools/deploy_audiobook_controls.py --port COM3` 安装听书 0.3.0，原应用资源备份到 SD；安装后再重启一次刷新桌面缓存的图标。

`tests/screen_lock_static.cpp` 覆盖两次短按、超时、长按重复、无按下的释放和毫秒回绕；听书 JS 回归覆盖选择框档位/非法选择/原生计时同步、移除跳转动作、锁屏不停止音频和 Q 版图标资源。

`tools/verify_audiobook_controls.py --port COM3` 检查实机选择框字体、档位和倒计时同步；添加 `--lock` 会保持锁屏供实体键验证，需手动连按两次音量＋解锁，结果保存在私有 runtime 目录。

本次 s3.23 / 0.3.0 实机已验证：应用分区 MD5 读回一致，重启后版本正确，四档选择框使用相同的 35px 行高字体并同步原生定时；倒计时不会被界面轮询重置，锁屏后音频继续输出。10 篇故事、保存音量/勿扰/息屏设置、书签和字库注册保持。用户实测确认触摸不唤醒、双按音量＋正常解锁，设备也记录到了触摸拦截和成功解锁。

0.2.2 为当前十篇故事补齐中文标题：小马和月亮灯、咕咚、小蝌蚪找妈妈、乌鸦喝水、小猴子下山、狐假虎威、坐井观天、小马过河、雪孩子、亡羊补牢。其他音频显示去掉扩展名的文件名，界面不再显示目录路径；播放路径和书签仍使用原始路径。

系统子集字库缺少“蝌”，应用随包提供 OFL 授权的 Noto Sans SC 单字补充字体，标题其他字符仍回退到系统中文字体。当前固件只支持全局注册字体，应用 root 不能包含 fontSet。旧设备的 0.2.2 标题补丁使用 `tools/deploy_audiobook_titles.py --port COM3`：备份原字库索引、安装 0.2.2、复制补充字体并保留原字体注册，重启一次加载字体。已经安装该补丁的设备无需再次运行此旧版安装器。s3.23 源码资源已包含补充字库；应用分区更新保留已有字库注册。

使用 `fonttools` 和本机 OFL 字体运行 `brookesia-apps/audiobook/tools/generate_title_font.py --font <NotoSansSC-VF.ttf>` 可重新生成补充字库；来源哈希与授权在 `src/res/fonts/`。

中间 PWR 键保留 PMU 开关机。两个侧键分别为 BOOT/GPIO0 音量减、KEY3/GPIO18 音量加，每次 5%，长按连续调整；尊重儿童音量上限与勿扰。息屏后的首次按键只唤醒，不同时调音量。BOOT 在上电/复位期间仍保持原有启动配置功能。

s3.21 将保存音量统一用于服务启动、编解码器重开和正在写入的音频流，避免界面数值变化但芯片输出不变。0% 会启用芯片静音，新的音量选择会保存；睡眠渐弱仍只改变 PCM 增益，不覆盖选择值。勿扰期间页面显示“音量 xx% · 勿扰静音”，保持已保存的音量。

`tools/verify_speaker_volume.py` 在播放中核对 10%、30%、0% 的芯片音量、DAC 寄存器与静音标志，测试后恢复当前音量和勿扰。可显式用 `--restore-volume` 指定恢复值；不改家长控制，需家长音量上限允许 30%。

新增大号“点一下说话 · 离线”按钮，先点按即可说短命令；不需要小智联网或云端识别。离线开关、模型与童声验证范围见 [OFFLINE_VOICE.md](OFFLINE_VOICE.md)。

## 睡眠定时

选 15、30、45 分钟，立即开始一次墙钟倒计时；暂停和切换章节不重新计时。最后 2 分钟对故事 PCM 施加线性数字增益，并把屏幕亮度渐降至原亮度的约 10%。屏幕若已自动熄灭，不会为了淡出重新点亮。

到时截停故事，使用离线中文短句“晚安”轻声播报，然后息屏；保留故事路径与位置，不会自动跳到下一章。勿扰或家长休息限制生效时跳过晚安语音，仍停止播放。取消定时恢复正常数字增益和先前亮度；到时息屏后恢复保存亮度供下次唤醒使用。

定时只在本次听书服务会话生效，关闭应用或重启取消；切换前台应用而听书仍保留在后台时，由原生轮询继续处理。倒计时未结束时暂缓自动深睡，避免暂停后被 10 分钟闲置规则提前打断。定时结束后自动深睡重新计时。原有 10 分钟显示息屏不变。

渐弱不修改系统音量或逐秒写 NVS；复用原有音频任务及设备轮询，不创建常驻睡眠定时任务。

- 《咕咚》：从淘知学堂课文原声朗读页面提供的下载链接获取，用于当前设备测试；来源、字节数和 SHA-256 记录于 `samples/stories/sources.json`，仓库不重新分发该音频。部署时使用 ASCII 文件名以适配当前 SD 文件系统编码，界面显示中文书名。

在中文 Windows 上可重新合成原创故事为 WAV，开发板同样支持 WAV：

```powershell
powershell.exe -NoProfile -File tools/synthesize_mandarin.ps1 -TextFile samples/stories/小马和月亮灯.txt -Output D:/story.wav
```

无需 API Key、网络 TTS 或接口费用；其他语音需要在本机已安装并通过 `-Voice` 指定。短句晚安以约 34 KB PCM 保存在固件 Flash，不依赖 SD 或网络。
