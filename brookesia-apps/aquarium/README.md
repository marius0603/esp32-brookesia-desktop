# 口袋鱼缸

微雪 ESP32-S3-Touch-AMOLED-2.16 上的 Brookesia 独立应用。480×480 像素鱼缸包含金鳞、月影、四条蓝线鱼和一只水母。

- 点水面产生水纹。金鳞会靠过来，蓝线鱼会结伴转向，附近的月影会游开。
- 点击鱼、水母或左上角的「鱼册」查看习性。水母会缓慢漂浮，伞盖周期性收放。
- 点击左上角的日景或夜景切换水景。夜景游速更慢，重新进入时会恢复上次选择。
- 从屏幕底边上滑回桌面。退出后暂停鱼缸绘制。

游动和触摸响应由本地规则驱动，可以离线使用。首版尚未接入端侧模型。

## 构建和安装

在仓库根目录运行以下命令。资源构建使用 Pillow，打包前会通过 Node.js 检查上述交互和定时器生命周期。

```powershell
python brookesia-apps/aquarium/tools/build_resources.py
python codex-quota-monitor/tools/package_aquarium.py
python codex-quota-monitor/tools/deploy_aquarium.py --port COM5
```

用设备的实际串口替换 `COM5`。BPK 通过现有安装器写入 SD。日夜偏好保存在 `/littlefs/aquarium-settings.json`。

0.1.4 在 s3.93 上使用固件的显示行缓存。水草、岩石、光束和装饰气泡固定。空闲时只重绘鱼和水母移动过的区域，点水面时更新水纹。切换日夜时更新底图。屏幕始终接收完整行，较早固件上由应用请求整行重画。

0.1.5 搭配 s3.94 使用原生 RGB565 合成。背景和鱼图一次读入，动画定时器更新位置并重画变化区域，行为定时器独立计算游动方向与触水反应。现有行缓存和 DMA 条带负责送屏，应用继续提供鱼册、日夜偏好及触摸。固件缺少原生渲染能力或原生画布无法启动时使用原来的绘制路径。

0.1.6 搭配 s3.95，让右侧小气泡错开上浮，左右两丛前景水草从固定根部向叶尖摆动。原生 RGB565 画布按 60 行分配横带，照常局部合成和整行送屏。原生启动及短时重试期间隐藏备用贴图层，减少切换应用时的图像解码占用。`art/under-grass-*.png` 补齐原水草遮住的日夜底图，打包为 `res/grass.bin`。在较早的固件上，水草沿用静态画面。

0.1.7 使用重新绘制的青蓝日景和深靛蓝夜景，以及扇尾金鳞、银蓝竖纹月影、蓝线鱼和紫色水母。左上角的「鱼册」与日夜切换按钮等宽、上下排列。日夜底图和独立鱼贴图从 SD 加载，兼容 s3.95 的原生渲染。
