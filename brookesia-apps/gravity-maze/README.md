# 小马迷宫 0.1.3

ESP32-S3-Touch-AMOLED-2.16 的离线重力迷宫，配套固件 **0.8.3-s3.67**。应用脚本、图片、提示音和进度位于 SD 卡，基础桌面、设置、家长验证、电源及恢复入口继续保留 Flash。

## 玩法

打开“小马迷宫”，点“开始找家”，按舒服的角度拿稳约一秒完成校准；轻轻向左右、前后倾斜，引导小马收集三颗星星并找到小屋。到达小屋即可过关，星星不作为惩罚或过关门槛。没有倒计时、生命值或失败扣分。

- 十关依次为 3×3、4×4、5×5、6×6、7×7、8×8、9×9、10×10、11×11、12×12。
- 每次打开或进入下一关生成新地图，同一关不会连续重复；暂停、校准和前后台切换保留本局地图。
- 前四关显示全图；从 7×7 起保持通道宽度，镜头跟随小马，右上角显示缩略图。
- “提示”显示通往小屋的前四格，四秒后隐藏；“暂停”停止采样，“校准继续”可重新设置握持基准。
- 底边上滑沿用系统返回手势。退出、休息、锁屏或息屏会停止移动并释放重力锁，回到应用后需要重新校准。
- 碰墙停住，不会穿墙或掉落。拾星和到达播放短提示音，遵守系统音量、儿童上限和勿扰；其他音频占用播放器时不抢占。

## 随机地图与重力

`engine.js` 使用有种子的随机 DFS 生成连通树，每格可达且通路唯一。各关主路径长度范围逐渐增加，三颗星分别放在主路三个区段，排除起终点。每轮最多尝试 192 次，未找到适当长度时使用已验证的对应关卡模板；若与前局相同，沿对角线转置，仍保留起终点和难度。这里保证有解、星星可达与连续不重复，不保证历史上永不重复。

输入同时考虑屏幕旋转角和设备保存的 IMU 校准偏移；20 个样本求握持基准，1.5°死区、约12°达到最大速度，最大速度120像素/秒，速度响应系数16/秒。0.1.3根据用户“不够灵敏”的反馈提高小角度响应与起步/停步速度，同时把短时画面延迟的运动时间步上限从50ms改为100ms，减少低刷新率时的额外减速。长延迟仍截断，碰撞每轴子步最大2px。摇晃过大或传感器数据超过250ms会停住，超过1秒暂停并要求重新校准，避免继续沿旧方向移动。当前重力判断针对轻倾斜，不支持倒置大翻转操控；输入灵敏度提升不代表复杂关渲染帧率提升。

固件 `AutoRotation 0.1.2` 复用原采样任务，提供 AcquireMotion / ReadMotion / ReleaseMotion。租约期间20ms轮询并暂缓自动旋转；每次读取续约，超过2.5秒自动释放。不会改写用户的自动旋转开关、锁定方向或校准值；QMI8658 本身的加速度输出频率仍为31.25Hz。应用渲染定时器目标33ms，实际帧率取决于整机负载，不将其描述为固定30FPS。

## 儿童模式与数据

家长页 **0.1.5** 将原“轻学习”选项显示为“学习/迷宫”，两个应用共用原权限位16，不迁移 PIN 或白名单存储；默认儿童配置仍不额外开启此项。须由家长通过现有验证自行授权。每日时长、夜间休息和音量上限仍由原生儿童策略执行。

`/sdcard/apps/local.gravitymaze/data/progress.json` 保存关卡和上局签名；`state.json` 保存有限的本局诊断信息，不包含语音、位置或账户信息。应用不使用网络、麦克风或云端服务。拔卡后迷宫不可用，基础系统仍可用。

## 构建与部署

仓库根目录运行（Python 需 Pillow，Node.js 在 PATH 或由现有 runtime_paths 找到）：

```powershell
python codex-quota-monitor/tools/package_gravity_maze.py
python -m unittest discover -s tests -p test_maze_native_contract.py
```

生成 `packages/apps/local.gravitymaze.debug.0.1.3.bpk` 和家长设置包；`src/app/main.js` 由 engine.js 与 controller.js 拼接，修改源文件后需重新打包。48像素小马和96像素桌面图标复用仓库原有小马素材，避免解码大尺寸纹理；星星、小屋和短提示音由打包脚本生成。

现有设备先使用项目的完整备份与 `flash_app_only.py` 流程安装 s3.67，仅替换应用分区并验证区外数据不变；再运行 `deploy_gravity_maze.py` 部署 SD 包、`deploy_child_audio_ui.py` 更新 Flash 家长界面，重启登记版本。部署工具校验包、来源资源和新树哈希，保留旧目录与进度；若上次更新记录缺失或来源被修改，会拒绝覆盖并要求检查。不要把本机 runtime 记录、整片备份或个人配置上传仓库。

`verify_gravity_maze.py` 检查租约释放/过期、静音 PCM 双声道输出、蓝牙重新开启、资源和原音量保留。它需要普通模式、无其他活动音频，不绕过家长验证。Node 测试覆盖400张随机地图、十关实际物理路径、16种旋转/校准组合、运行时生命周期以及深浅配色至少7:1的文字对比度。实机方向、阅读效果与最高关负载的现场结论见 [VERIFICATION.md](VERIFICATION.md)。复杂地图分批创建视图和提交绑定，加载时不提前获取运动租约；最高关CPU开销仍高，保留后续优化空间。
