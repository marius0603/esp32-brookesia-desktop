# 猫咪表盘素材

2026-11-09：用户确认新版橘猫设计后授权实装，并要求按日出日落切换昼夜。
两张原始图集由内置 imagegen 生成，不含账号、服务密钥或下载的商业插画。
夜景以用户提供的橘猫敲键盘照片为构图参考；白天版保留各帧姿势，改变窗外与照明。
提示词保存在本目录。图集为两列四行，按行取八个姿态。

`tools/cat_animation.py` 裁切等分图集、缩放至340×150、编码为原生RGB565/RLE，
并输出白天/夜晚预览。`animation.json` 记录输入SHA256与帧参数。
素材仍存在少量逐帧几何变化，实机动画观感需由用户确认；不描述为完美注册的逐帧动画。
