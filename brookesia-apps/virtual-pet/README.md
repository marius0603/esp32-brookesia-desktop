# 电子宠物 · 小栗

应用 `local.virtualpet` 0.1.3，面向 480×480 的 ESP32-S3-Touch-AMOLED-2.16；配合s3.36固件的应用退出资源释放。

小栗是栗色小马，奶油色鼻子、深棕鬃毛和青绿色围巾。日常眨眼与轻微起伏，用餐时咀嚼，睡觉时闭眼盖被并轻微起伏。八张预先对齐的320×320 RGB565/RLE原生帧按当前动作预载：日常/开心三张、吃饭三张、睡觉两张。手动缓存最多614,400字节，切换动作先释放上一组；界面还会短暂保留当前显示帧的引用，不在每帧读取SD或解码PNG。相较旧版同时预载八帧的1,638,400字节，降低打开应用时的内存峰值。呼吸和开心起伏使用设备原生往返动画；眨眼以65ms补间过渡，睡觉姿态以145ms过渡。吃饭每160ms更新单张不透明姿态，并隐藏叠加层，避免两个鼻子和饭碗产生重影。逻辑定时器为50ms，实际显示速度取决于设备重绘，并非保证20帧。

s3.36切换应用时关闭旧页面并释放脚本运行环境。宠物仍兼容旧固件的前台检测，离开后停止动作和手动帧缓存；正式暂停/停止时停止定时器。动画帧不再固定随文档预载，显示中的帧由界面引用管理，页面关闭后释放。重新打开时按真实时间恢复作息。

## 使用

- 桌面打开“电子宠物”。“喂食”播放约12秒吃饭，“陪伴”或点小栗播放约6秒开心动作，然后回到当时的作息。
- “作息”查看三餐及睡觉时间。“看看睡觉”临时展示12秒睡觉动画，随后自动恢复；不会改变设备时钟或保存成睡觉状态。
- 默认北京时间：早餐07:30、午餐12:00、晚餐18:30，各持续30分钟；22:00至次日07:00睡觉。睡觉期间不会被喂食、陪伴唤醒。
- 退出、重启或再次打开，直接根据当前真实时间决定状态，不补播过去的饭点。首次开机尚未校时时显示“等待校时”，保持日常动画；联网校时后自动恢复作息。校时完成后的短暂断网不影响走时，不依赖电脑或云端模型。
- 此版不含宠物叫声、饥饿数值、惩罚或死亡机制。睡觉是宠物画面状态，不会替用户改变屏幕亮度、音量或设备息屏设置。

## 资源和作息配置

`content/schedule.json` 安装至 `/sdcard/pets/xiaoli/schedule.json`。`start`、`end` 是当天0点起的分钟数；例如450为07:30，1320为22:00。当前支持 `Asia/Shanghai`、UTC+480分钟。配置无效时使用安全默认作息；更新安装会保留已有作息文件。改完后重开应用生效，暂不提供界面内修改时间。

`assets/source/` 保留 imagegen 内置工具生成的三张原始图集，生成要求见 [PROMPTS.md](assets/source/PROMPTS.md)。`tools/build_assets.py` 只负责帧裁切、位置对齐、尺寸转换及原生格式导出，RLE编码独立解码后逐像素核对。`assets/frames-preview.png` 为全部八帧预览。此版是关键姿态与设备补间结合的轻量动画，尚不包含行走、完整骨骼动作或视频播放。

## 构建与安装

Python需要 Pillow；无需重新生成图片或调用模型。

```powershell
python brookesia-apps/virtual-pet/tools/build_assets.py
python brookesia-apps/virtual-pet/tools/build_screen.py
python codex-quota-monitor/tools/package_virtual_pet.py
# 关闭串口采集器后，替换为设备实际端口
python codex-quota-monitor/tools/deploy_virtual_pet.py --port COM3
```

提供小型应用包 `packages/apps/local.virtualpet.debug.0.1.3.bpk` 和独立 SD 资源包 `packages/content/virtual-pet-xiaoli-1.0.0.zip`，校验值在 `packages/SHA256.json`。部署器对每个上传文件校验SHA256，复制后检查尺寸，覆盖前备份至设备 `/sdcard/resource-backups/virtual-pet-时间戳`。较大原生帧通过现有受限 SD 上传通道暂存，避免占满 Flash；应用通过标准BPK安装器安装到SD，结束后恢复原安装存储策略。

部署器只给当前 Shell 图片目录补充 `cyber.local.virtualpet`，保持新应用在两套主题中都能显示图标；不覆盖现有十个主题图标、壁纸或桌面布局。首次安装后重启一次加载新 Shell 资源，再打开电子宠物。SD卡需要一直保留，卡缺失时应用不可用。

自动逻辑检查覆盖三餐边界、跨夜睡觉、校时、预览到期、无每帧写盘及前后台定时器。`verify_virtual_pet.py --port COM3` 临时安装检查版，验证全部八帧和交互后恢复正式BPK，再验证前后台切换、故事、音量和主题保留；私有日志留在忽略的 `codex-quota-monitor/runtime/`。

2026-10-29，历史版本0.1.2已安装并通过以上实机检查；用户观察吃饭后确认：“没有重影，动作可以”。保留原10篇故事、书签、听书模式、音量75及原桌面主题选择。源码、原稿和两个可安装包随本次版本同步，未改写固件。

2026-10-30，0.1.3搭配固件s3.36在Wi-Fi与BLE开启时通过全部八帧、喂食/陪伴/作息/睡觉预览、时钟同步和退出重开检查；正式BPK已恢复，10篇故事、听书偏好、作息和经典Q版主题保留。

## 回退

关闭电子宠物并通过应用管理卸载；需要撤回新增 Shell 图片条目时，从本次部署备份的 `shell-images.json` 恢复 `/littlefs/system/super/shell/images/index.json`，再重启。确认不再需要时可删除 `/sdcard/pets/xiaoli/`，不要移除其他宠物、主题或应用目录。安装器的电脑端私有报告记录确切备份位置，仓库不包含运行记录和个人数据。
