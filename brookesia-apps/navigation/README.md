# 小马导航 0.2.2

0.2.2按路口事件播报：远处和不变指引保持安静；100米内、30米内各提醒一次，通知文字变化不会重复播报。从30米内转向切换到150米以外的下一段指引时，仅播一次中性的“请继续按导航行驶。”；这是通知距离切换提示，不是设备独立定位确认已过路口。到达提示一次。保留手动重播、音量和勿扰保护。需配套s3.66（LearningAudio 0.1.1）。

s3.66将导航16KiB任务栈放入PSRAM，纯播放不再获取Recorder；其他学习/录音和Flash敏感控制任务仍用内部栈。内部DMA预留池96→128KiB，蓝牙保护门槛不变。三轮真实加密BLE/多段语音PCM/暖重开通过，关闭后最大连续DMA块均30720字节，恰等于门槛；旧学习App兼容及第四次蓝牙开启通过。保留15应用、30故事、30歌曲和原音量。有限轮次不代表任意长期负载均无内存不足，真实路口时机仍需手机通知现场验证。

0.2.1按用户反馈保留路名并截掉“｜”等分隔附加内容、清理特殊图标字符。增加“重播”按钮；重新开启语音时立即尝试播报当前有效指引，手动重播仍遵守勿扰/音量和导航有效期，未知方向仅播“按手机提示”，不猜测转向。

配套s3.65将导航提示从单声道改为与听书相同的双声道16kHz I2S输出，复用既有缓冲复制左右声道，并在打开后重新拉动功放使能、等待30ms稳定；只改导航模式，不改变原学习录音/播放。软件PCM写入不等于喇叭已出声：用户此前确认单声道直接重播仍无声音；2026-11-11更新后用户已确认“能听到清楚的语音”。

0.2.0实装图形优先布局：中间大箭头与居中距离、精简通知文字，顶部显示系统音量及电池；底部语音开关和图形音量加减按钮。读取系统音量，每秒更新，支持实体键联动；音量按5%调整、0～100%限制由系统继续执行。图形/深浅色及原语音逻辑复用，固件仍s3.64，仅更新SD应用。

ESP32端为蓝牙指引显示器：箭头、转向距离、通知文字、剩余距离/时间、数据状态及本地语音开关。需要s3.64与SD卡；定位、算路和实际导航由手机高德App完成。设备无需Wi-Fi，不独立定位、算路或显示地图。

推荐手机安卓0.5.0的“导航通知转发”。它只读取用户授权后由`com.autonavi.minimap`提供的通知字段。尚未识别的方向用中性手机图标；未知数值为`--`，不会补为0或猜测路线。真实通知字段和更新频率因手机/高德版本而异，需要实机核对。开发者SDK的旧私有试验仍保留为独立研究入口，公开APK不包含SDK/Key或联网权限。

## 语音

中文固定提示完全离线，25份16kHz/16bit单声道WAV存于本App的SD目录。用Windows System.Speech/Huihui生成，重建脚本为`tools/build_navigation_prompts.ps1`，音频文本及哈希见`src/res/audio/sources.json`。不进行在线TTS，不朗读任意道路名称。

直行、左/右转、左/右前方、掉头和到达提示；100米内、30米内各提醒一次，同向阶段提醒至少4秒间隔（30米紧急阶段除外）；方向改变时取消旧提示。未知方向不自动播报，手动重播为中性提示。复用LearningAudio的独占播放器，其他音频占用时不抢播；跟随系统音量及勿扰，静音/过期/停止/退到后台时取消导航提示。仅允许白名单提示编号，无任意文件或音频URL接口。儿童模式仍不开放导航。

## 协议与生命周期

复用原Security1 BLE会话和256字节请求上限；`cmd=nav`，`s`16位十六进制会话，`q`递增序号，`m`来源0离线/1SDK模拟/2高德通知，`t`方向0直行、1左、2右、3左前、4右前、5掉头、6到达、7未知；`d/r/e`转向米数/剩余米数/剩余秒（-1未知），`n`最多72 UTF-8字节，`z`0进行/1到达/2停止。

新会话必须q=1、z=0，重复/倒序/来源变更/停止后续传拒收。数据仅RAM保存，15秒未收到新包即过期。手机0.5.3定期核对系统中的活动导航通知，仍存在时同步其原始内容，内容变化年龄与系统核对时间分开；通知移除/结束/无法核对时停止，绝不根据旧指引推算新距离。蓝牙关闭时结束缓存会话，不反复唤醒屏幕或写Flash。

通过`DeviceModes.GetNavigationState`读取缓存，不新增常驻任务。界面1秒刷新且文本/图片未变化时不重绘，支持系统深浅色，暂停时停止轮询和播报。

## 构建与部署

`python codex-quota-monitor/tools/package_navigation.py`运行UI/生命周期/语音去重回归并生成BPK。`deploy_navigation.py --port COM5`逐文件暂存到SD，整树哈希校验后原子切换；更新时只允许与已记录部署哈希一致的旧树，保留旧目录。重启并等待完整桌面启动后再打开App。

真实加密BLE测试：`phone-remote/tests/verify_navigation_device.py`。合成帧不调用高德。用户通知与地址仅在手机/设备RAM显示，不写测试报告或上传GitHub。

多轮暖启动：`phone-remote/tests/verify_navigation_memory.py --port COM5 --rounds 3 --tools <本机Android工具JSON> --classes <临时Java类目录>`。设备需空闲、解锁、关闭儿童模式与既有蓝牙会话；临时静音并关闭自动深睡，结束恢复原值和电脑蓝牙状态。报告仅记录测试结果及内存，不保存配对码或真实道路。
